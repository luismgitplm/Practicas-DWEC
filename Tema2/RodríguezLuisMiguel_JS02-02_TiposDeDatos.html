  1. ¿Qué etiqueta se utiliza para insertar código JavaScript en HTML?
    La etiqueta script.
  2. ¿Qué ventajas tiene incrustar el código JavaScript en un archivo externo?
    Facilita la reutilización, mantenimiento y mejora el rendimiento al poder ser almacenado en caché.
  3. ¿Qué extensión suelen tener los archivos que contienen código JavaScript?
    Tienen la extensión .js.
  4. ¿Cómo se referencia un archivo .js en HTML?
    Con script src="archivo.js"/script.
  5. ¿Qué debe hacer si el archivo JavaScript se encuentra en otro directorio?
    Especificar la ruta relativa o absoluta en el atributo src del script.
  6. ¿Qué etiqueta se usa para mostrar un mensaje si el navegador no soporta JavaScript?
    La etiqueta noscript
  7. ¿Qué diferencia hay al insertar JavaScript en XHTML?
    En XHTML se debe usar CDATA para que el código JS no sea tratado como texto HTML.
  8. ¿Qué es la ofuscación de código y por qué se utiliza?
    Es hacer el código difícil de leer para protegerlo contra copia o ingeniería inversa.
  9. ¿Qué nombre le dio Microsoft a JavaScript?
    Microsoft lo nombró JScript.
  10. ¿Por qué Microsoft usó el nombre Jscript?
    Debido a problemas de licencias, ya que "JavaScript" era una marca de Netscape.
  11. ¿Qué problema surgió con la versión de JScript de Microsoft?
    No era totalmente compatible con JavaScript estándar, generando errores en algunos navegadores.
  12. ¿Qué es el DOM y por qué fue diseñado?
    El DOM (Document Object Model) es una interfaz que fue diseñada para manipular documentos HTML y XML como objetos.
  13. ¿Qué navegadores incorporaron el DOM desde su primera versión?
    Lo incorporaron Internet Explorer 5 y Netscape 6.
  14. ¿Qué estándar regula el lenguaje JavaScript desde 1997?
    Lo regula la especificación ECMAScript.
  15. ¿Qué documento detalla las especificaciones del estándar ECMA?
    El documento ECMA-262.
  16. ¿Qué relación tiene JavaScript con Java?
    Sólo comparten una sintaxis similar; son lenguajes distintos.
  17. ¿Quién desarrolló originalmente JavaScript y con qué nombre?
    Brendan Eich en Netscape; originalmente se llamó Mocha.
  18. Usa la función alert para enseñar el mensaje "holamundo"
    <script>alert("holamundo");</script>
  19. Declara varias variables en una sola línea
    let a = 5, b = "texto", c = true;
  20. ¿Qué caracteres y nombres están prohibidos como nombre de variables?
    No se pueden usar palabras reservadas ni comenzar con números. Tampoco se permiten espacios ni símbolos como +, -, !, etc.
